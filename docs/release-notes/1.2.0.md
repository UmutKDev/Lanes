# Lanes 1.2.0

- **Oturumu başka hesaba taşı:** Claude uygulamasının Code sekmesinde başlayan bir oturum artık öteki hesabın Code sekmesinde, konuşmanın tamamıyla açılıyor. Oturumlar sayfasında oturumlar Code sekmesindeki başlıklarıyla görünüyor. Satırdaki **Taşı** düğmesiyle istediğin oturumu seçtiğin hesaba taşıyabilirsin. Hedef uygulama açıksa Lanes onu yeniden başlatmadan önce sorar. Asıl oturum kaynak hesapta olduğu gibi kalır.
- **Limite takılınca tek tık:** "Limite Takıldı" menüsündeki **Son Oturumu X Hesabına Taşı** hesabı 5 saat dinlendirir ve en son oturumu sıradaki hesapta açar.
- **Geri alma:** Oturumlar sayfasındaki **Son Taşımalar** menüsünden bir taşımayı geri alabilirsin. Lanes'in kopyaladığı dosyalar Çöp Sepeti'ne gider.
- **Tarayıcı eklentileri:** Eklenti hesapları Lanes'tekilerle kendiliğinden eşliyor. Edge'de eklenti artık Edge Eklentileri mağazasından kuruluyor.

# Lanes 1.2.0 (English)

- **Move a session to another account:** a session started in the Claude app's Code tab now opens in the other account's Code tab with its whole conversation. The Sessions page shows sessions by their Code tab titles. Use the **Move** button on a row to move any session to the account you choose. If the target app is open, Lanes asks before restarting it. The original session stays as it is in the source account.
- **One click when you hit a limit:** **Move Last Session to X** in the "Limit Reached" menu rests the account for 5 hours and opens the latest session in the next account.
- **Undo:** you can undo a move from **Recent Moves** on the Sessions page. The files Lanes copied go to the Trash.
- **Browser extensions:** the extensions match accounts with the ones in Lanes on their own. On Edge, the extension now installs from the Edge Add-ons store.
