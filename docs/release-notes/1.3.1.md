# Lanes 1.3.1

- **Homebrew ile kurulum:** `brew tap umutkdev/lanes https://github.com/UmutKDev/Lanes` ve ardından `brew install --cask lanes`. Lanes kendini güncellemeye devam ediyor, `brew upgrade` ona dokunmuyor.
- Eklentinin ayarlarında Lanes masaüstü uygulaması bulunamadığında artık eklentinin onsuz da çalıştığı yazıyor.

# Lanes 1.3.1 (English)

- **Install with Homebrew:** `brew tap umutkdev/lanes https://github.com/UmutKDev/Lanes`, then `brew install --cask lanes`. Lanes still updates itself, and `brew upgrade` leaves it alone.
- When the Lanes desktop app isn't found, the extension's settings now say that the extension works without it.
