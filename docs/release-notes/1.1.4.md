# Lanes 1.1.4

- **Eklenti hesapları kendiliğinden eşleşiyor:** Safari, Chrome ve Edge eklentisi bir claude.ai hesabını Lanes'teki hesabıyla artık e-posta yoksa da claude.ai hesap numarasından tanıyor. Web hesabı Lanes'teki adını ve rengini alıyor.
- **Edge mağazası:** Edge eklentisi artık Microsoft Edge Eklentileri'nde. Lanes'in Entegrasyonlar sayfasındaki "Mağazadan Kur" düğmesi oraya götürüyor.
- **Homebrew ile kurulum:** `brew tap umutkdev/lanes https://github.com/UmutKDev/Lanes` ve ardından `brew install --cask lanes`.

# Lanes 1.1.4 (English)

- **Extension accounts match on their own:** the Safari, Chrome and Edge extension now recognizes a claude.ai account's Lanes twin by its claude.ai account number, even without an e-mail. The web account takes its name and color from Lanes.
- **Edge store:** the Edge extension is now on Microsoft Edge Add-ons. The "Install from Store" button on Lanes's Integrations page goes there.
- **Install with Homebrew:** `brew tap umutkdev/lanes https://github.com/UmutKDev/Lanes`, then `brew install --cask lanes`.
