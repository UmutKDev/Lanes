# Lanes 1.0.1

- Mevcut bir Claude klasörünü içe aktar: Claude'u kendi script'inle ayrı bir klasörle açıyorsan, Hesap Ekle'den o klasörü Lanes hesabına taşı. Giriş ve yerel oturumlar korunur, eski kısayolu Çöp Sepeti'ne taşımayı önerir.
- Bir hesabın Claude Code'u istersen ortak ~/.claude klasörünü kullanabilir.

# Lanes 1.0.1 (English)

- Import an existing Claude folder: if you open Claude with your own script and a separate folder, move that folder into a Lanes account from Add Account. Sign-in and local sessions are kept, and Lanes offers to move the old launcher to the Trash.
- An account's Claude Code can use the shared ~/.claude folder if you want.
