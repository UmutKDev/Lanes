# Lanes 1.1.1

- **Chrome ve Edge eklentisi:** Safari eklentisinin aynısı artık Chrome, Edge ve diğer Chrome tabanlı tarayıcılarda da var. Mağazalarda yayımlanana kadar Ayarlar > Entegrasyonlar > Chrome ve Edge eklentisi > Eklentiyi Yükle ile kurulur.
- Lanes kuruluysa eklenti oturumları Anahtar Zinciri'nde saklar, hesaplar Lanes'teki adını ve rengini alır.
- Claude in Chrome yalnız claude.ai'de kendi hesabı açıkken çalışır. Hesap ayarlarında "Claude in Chrome bu hesapta" seçilirse, başka hesaba geçince eklenti tek tıkla geri dönmeyi önerir. Claude in Chrome ya da Claude Code bir sekmede giriş yaparken hesap değiştirilmez.
- Safari eklentisinde hesap listesindeki adlar daha okunaklı. Hesap adıyla aynı kurum etiketi artık gösterilmiyor.

# Lanes 1.1.1 (English)

- **Chrome and Edge extension:** the Safari extension now also works in Chrome, Edge and other Chrome-based browsers. Until it is in the stores, install it from Settings > Integrations > Chrome and Edge extension > Load Extension.
- With Lanes installed, the extension keeps sessions in the Keychain and accounts take their names and colors from Lanes.
- Claude in Chrome only works while claude.ai is signed in to its own account. Mark that account with "Claude in Chrome uses this account" and the extension offers a one-click way back when you switch away. Accounts aren't switched while Claude in Chrome or Claude Code is signing in in a tab.
- In the Safari extension, account names in the list are easier to read, and an organization chip that repeats the account name is no longer shown.
