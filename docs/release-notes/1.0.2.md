# Lanes 1.0.2

- Claude uygulamasının hesabı artık "Ana hesap" adıyla geliyor. Adını değiştirmediysen bir kez kendiliğinden düzeltilir.
- Ana hesaba renk verilebiliyor ve Kimlik sekmesi var.
- Claude Code uygulamadan farklı bir hesaba giriş yapmışsa, onun e-postası artık hesabınki gibi gösterilmiyor; kartta başında "Claude Code:" yazıyor.
- Bir hesapta "~/.claude ile ortak" kapatılınca, o hesabın Claude uygulamasındaki Code oturumları yeni klasörüne kopyalanıyor. Önceden "Oturum diskte bulunamadı" çıkıyordu. Ayarı daha önce kapattıysan Claude Code sekmesindeki "Oturumları ~/.claude'dan Kopyala" düğmesini kullan.

# Lanes 1.0.2 (English)

- The Claude app's account is now named "Main account". If you never renamed it, it is fixed once automatically.
- The main account can have a color and has an Identity tab.
- When Claude Code is signed in to a different account than the app, its email is no longer shown as the account's; the card labels it "Claude Code:".
- Turning off "Shared with ~/.claude" for an account now copies that account's Claude app Code sessions into its new folder. Before, the app showed "Session not found on disk". If you turned it off earlier, use "Copy Sessions from ~/.claude" on the Claude Code tab.
