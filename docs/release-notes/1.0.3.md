# Lanes 1.0.3

- Bir hesapta "~/.claude ile ortak" kapatılınca, o hesabın Claude uygulamasındaki Code oturumları yeni klasörüne kopyalanıyor. Önceden "Oturum diskte bulunamadı" çıkıyordu.
- Ayarı daha önce kapattıysan, hesabın Claude Code sekmesindeki "Oturumları ~/.claude'dan Kopyala" düğmesine bir kez bas. ~/.claude değişmez.

# Lanes 1.0.3 (English)

- Turning off "Shared with ~/.claude" for an account now copies that account's Claude app Code sessions into its new folder. Before, the app showed "Session not found on disk".
- If you turned it off earlier, press "Copy Sessions from ~/.claude" once on the account's Claude Code tab. ~/.claude doesn't change.
